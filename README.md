# DSA Tracker

Local-first A2Z DSA progress and revision tracker.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
This is a static Vite app. It can be deployed to Vercel, Netlify, GitHub Pages, or any static host.

## Data
Problem metadata lives in `data/problems.json`. Personal progress and notes stay in browser localStorage. Use Settings → Export to back up your data.

## Current seed
The repository starts with a small seed dataset so the UI is immediately usable. Replace/extend `data/problems.json` with the full A2Z dataset you are using.
