Three co-located modules form a minimal serverless API surface with one-way dependencies: `_session.js` is a shared utility that issues, validates, and clears an HMAC-SHA256 signed cookie (`dsa_tracker_session`) carrying a base64url-encoded expiry payload; `auth.js` mounts as `/api/auth` (GET/POST/DELETE) and uses `_session` to expose authentication status, sign in, and sign out; `state.js` mounts as `/api/state`, guards every route with `hasSession`, lazily ensures a single-row `dsa_tracker_state` table via a module-scoped `ensureTablePromise` on cold start, and supports GET retrieval and POST upsert of a sanitized JSONB state. There are no cross-imports between `auth.js` and `state.js`; both depend only on `_session.js`. Configuration is entirely environment-driven through `SESSION_SECRET`, `APP_ACCESS_PASSWORD`, and `DATABASE_URL`.
