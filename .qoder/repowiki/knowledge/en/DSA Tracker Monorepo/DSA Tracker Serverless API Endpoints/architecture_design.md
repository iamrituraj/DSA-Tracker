Four co-located CommonJS modules form a flat, single-level API surface with one-way dependencies: `_session.js` is the shared session layer that issues, validates, and clears an HMAC-SHA256 signed cookie (`dsa_tracker_session`) carrying a base64url-encoded expiry payload; `auth.js` mounts as `/api/auth` (GET/POST/DELETE) to expose sign-in, sign-out, and authentication status using `APP_ACCESS_PASSWORD`; `state.js` mounts as `/api/state` and `solutions.js` mounts as `/api/solutions`, both guarded by `hasSession` and each lazily ensures its own single-row `dsa_tracker_state` / `dsa_solutions` table via a module-scoped `ensureTablePromise` so schema creation runs once per cold start. There are no cross-imports between route handlers — they depend only on `_session.js` and `@neondatabase/serverless`. Configuration is entirely environment-driven through `SESSION_SECRET`, `APP_ACCESS_PASSWORD`, and `DATABASE_URL`, with Vercel auto-detection of HTTPS via `process.env.VERCEL` to set the Secure flag on cookies.
