The root `package.json` is the single orchestration point: `dev`/`build`/`preview` run Vite to serve the React SPA (entry `index.html` → `/src/main.jsx`), which consumes curated JSON from `data_assets/` and calls the `api_server`'s session/auth endpoints for state persistence; both the API layer and the client-side code use the same `@neondatabase/serverless` package to target the shared Neon PostgreSQL instance. Cross-child data workflows are exposed as top-level npm scripts (`prepare-data`, `extract-tuf-links`) that invoke Node modules under `scripts/` to regenerate the `data_assets/` JSON, keeping transformation logic separate from runtime app code.
