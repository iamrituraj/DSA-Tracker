The root `package.json` is the single orchestration point that wires three child concerns into one project: the Vite+React SPA (entry `index.html` → `/src/main.jsx`) consumes curated JSON from `data_assets/`, calls the `api_server`'s Neon-backed session/auth endpoints for state persistence, and uses the same `@neondatabase/serverless` client on the client side to sync directly with PostgreSQL. The npm scripts in this root package delegate cross-child workflows — `prepare-data` and `extract-tuf-links` invoke Node modules under `scripts/` to regenerate the `data_assets/` JSON, while `dev`/`build`/`preview` serve the SPA bundle that depends on both the data assets and the API layer.
