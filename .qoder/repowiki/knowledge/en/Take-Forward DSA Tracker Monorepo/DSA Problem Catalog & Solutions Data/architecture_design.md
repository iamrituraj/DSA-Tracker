Pure data module with no runtime code; two parallel directories serve different audiences. `data/` is the canonical source-of-truth used by build/tooling: `problems.json` (array of ~4k problem records), `patterns.json` (topic-to-pattern-name map), `topics.json` (flat top-level topics), and `problems.raw.json` (intermediate/raw dump). `public/data/` is the browser-consumable subset that mirrors `problems.json`, `patterns.json`, `topics.json` and adds `solutions.json` (`{problemId -> {approaches:[...]}}`) and `tuf-links.json` (`{problemId -> takeuforward URL}`). Consumers read these files directly as static assets — dependency direction is one-way from application code to these JSON schemas, with no import-time bundling.
