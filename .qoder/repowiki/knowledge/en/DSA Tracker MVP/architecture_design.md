The root package wires three child concerns into one Vite-based SPA: the React UI (entry `index.html` → `/src/main.jsx`) consumes curated problem/solution data from the `data_assets` module, invokes the `api_server`'s Neon-backed authentication and state-persistence endpoints for session management, and is bootstrapped via npm scripts that also invoke the `scripts` module's data preparation tools (`prepare-data`, `extract-tuf-links`). The `@neondatabase/serverless` client is shared between the UI and the API layer to talk to the same PostgreSQL instance.
