Three independent ES-module (.mjs) Node.js scripts, each a self-contained CLI tool with no shared library: `prepare-data.mjs` reads `data/problems.raw.json`, filters out theory/intro problems via regex title matching, normalizes topics through `shortTopic()`, classifies each problem into a TakeUForward pattern bucket using the inlined `TUF_PATTERNS` table (topic → subcategory → regex rules), and writes normalized `problems.json`, `topics.json`, and `patterns.json` to both `data/` and `public/data/`. `extract-tuf-links.mjs` parses an offline HTML dump of the A2Z page (`/private/tmp/tuf-a2z.html`) with regexes to extract item slugs and source URLs, then joins them against `public/data/problems.json` by normalized title, source URL, or slug to produce `public/data/tuf-links.json`. `java-to-csharp.mjs` exports a pure function `javaToCSharp(src)` that performs chained regex-based token replacements mapping Java types, collections, and methods to their C# equivalents and prepends standard `using` directives. Dependency direction is one-way: scripts read from the repo's `data/` tree and write back into it; there are no cross-imports between scripts.
