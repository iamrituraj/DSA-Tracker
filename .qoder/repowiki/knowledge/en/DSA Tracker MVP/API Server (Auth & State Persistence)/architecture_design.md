Three co-located Node.js modules form a minimal serverless API surface. `_session.js` is a shared utility that issues, validates, and clears an HMAC-SHA256 signed cookie (`dsa_tracker_session`) with a 30-day expiry; it exposes `issueSession`, `hasSession`, `clearSession`, and `safeEqual`. `auth.js` mounts as a handler for `/api/auth`: GET returns current auth status, POST accepts a password from `APP_ACCESS_PASSWORD` and issues a session cookie, DELETE clears it, and any other method returns 405. `state.js` mounts as a handler for `/api/state`: it guards all routes with `hasSession`, lazily creates a single-row `dsa_tracker_state` table in a Neon serverless Postgres connection (via `@neondatabase/serverless`), supports GET to retrieve the JSONB state and POST to upsert a sanitized state object, and returns structured error responses on missing env vars or DB failures. Dependency direction is one-way: both `auth.js` and `state.js` depend on `_session.js`; there are no cross-imports between the two handlers.
